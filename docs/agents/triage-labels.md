# Triage Labels

Matt skills 使用五个统一的 triage 角色；本项目直接使用同名 GitHub 标签。

| Skill label | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者判断下一步 |
| `needs-info` | `needs-info` | 等待请求方补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可由 Agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工执行或关键人工输入 |
| `wontfix` | `wontfix` | 确认不处理 |

当 skill 提及某个 triage 角色时，使用表中对应的 GitHub 标签。修改标签名称时必须同步更新本文件。
