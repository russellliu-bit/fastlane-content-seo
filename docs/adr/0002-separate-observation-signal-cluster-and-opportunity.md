# Separate Observation, Signal Cluster, and SEO Opportunity

SEO 工作模型采用 `Source Observation → Atomic Signal → versioned Signal Cluster → SEO Opportunity` 四层关系，而不让来源记录或聚类结果直接成为选题。额外关系和版本成本换取了来源 revision 可追溯、重复与转载可控、反向证据不被平均掉，以及 Heyup 与 DTC 模式共享底座但独立决策的能力。

`support`、`counter`、`context` 属于 Signal 在某个 Cluster 中的 membership role；Evidence Reference 本身保持中立。跨来源但同源转载保留各自血缘，并通过 Evidence Family 在独立佐证计数中合并。
